SP2 Engine Synth

How it works

Read MIDI notes

The converter extracts each track's note timing and pitch data from the uploaded MIDI file.

Map pitch to RPM

Notes are translated into calibrated engine RPM targets for SimplePlanes 2 Funky Trees expressions.

Paste into SP2

Copy each generated track expression into an engine controller, using one engine per track.

Note: this generator assumes standard engine configuration and tuning as in the provided demo craft.
